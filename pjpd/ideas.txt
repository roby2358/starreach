Port to Rust: move the TypeScript app layer (MCP handling, GameStore, viewers, view ids) and the adapters into Rust, so the whole stack is one language. On Cloudflare that would mean workers-rs, with the Durable Object written in Rust and no WASM-to-JS boundary. Weigh: maturity of workers-rs for Durable Objects (SQLite storage, hibernating WebSockets), Rust MCP SDK support for stateless streamable HTTP, what happens to the local Node adapter (a native Rust binary instead?), and the cost of rewriting the existing tests. Best decided before or alongside the Cloudflare adapter work, since that is the biggest new chunk of TypeScript.
